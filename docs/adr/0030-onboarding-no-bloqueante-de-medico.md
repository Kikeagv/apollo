# Onboarding no bloqueante de Médico

**Estado:** Aceptada  
**Fecha:** 24 de agosto de 2026

Un Médico con perfil incompleto podrá entrar al shell de Panacea y usar las
superficies permitidas, pero verá el progreso de configuración en
Configuración → Equipo y avisos contextuales cuando su perfil no sea elegible
para atender. Servicios y Disponibilidad bloquearán únicamente las acciones
que requieran un Médico elegible; no se reemplazará toda la aplicación por un
formulario de onboarding.

## Consecuencias

- La configuración inicial tendrá una lista de pasos clara y recuperable.
- La Agenda no presentará al Médico incompleto como disponible para nuevas
  Opciones de atención.
- Las Secretarias y otros Médicos no verán pasos de onboarding que no les
  correspondan.
