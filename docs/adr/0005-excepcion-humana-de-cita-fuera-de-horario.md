# Excepción humana de Cita manual fuera de horario

Panacea permite que un Médico o Secretaria cree una Cita manual fuera del Horario vigente tras una advertencia y confirmación explícita. La excepción existe para resolver la operación humana de la Clínica, pero omite únicamente el Horario: la Agenda sigue protegiendo Bloqueos, Citas, Reservas temporales, duración y buffer; Asclepio solo puede confirmar Opciones de atención calculadas.
