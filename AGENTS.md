## Agent skills

### Issue tracker

Issues are tracked in Linear, team `APO`. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default five-label vocabulary in Linear. See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses the single-context layout. See `docs/agents/domain.md`.

### Git commits

All commits must use the Conventional Commits format: `type(optional-scope): imperative summary`. Use an appropriate type such as `feat`, `fix`, `docs`, `refactor`, `test`, `build`, `ci`, or `chore`; do not create commits that do not follow this format.
